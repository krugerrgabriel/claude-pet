# Prompts de conceito para o ChatGPT

Cada prompt pede uma folha só, com as 8 poses: 1 imagem por personagem, para render no plano grátis.
Os prompts estão em inglês porque o gerador de imagem obedece melhor. Copie o bloco inteiro.

Salve cada resultado em `~/claude-pet/art/refs/<nome>.png` (ex.: `pato.png`).
A imagem é só **referência**: a versão final é redesenhada em grade de pixel real, então não precisa sair perfeita.

Ordem sugerida, se a cota acabar: pato → capivara → slime → gatinho → fantasminha → dentinho → robô.

## Se der errado

- **As poses saem desalinhadas ou o personagem muda de uma pra outra:** tudo bem, a ideia é só pegar o visual.
- **Cota acabando:** troque o pedido das 8 poses por `Show only ONE pose: the character standing, front view, centered.` Uma pose já me basta para eu derivar as outras.
- **Gostou do visual mas quer ajustar:** peça na mesma conversa algo como "same character, make the eyes bigger", em vez de começar outra conversa.
